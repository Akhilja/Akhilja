### 🧭 About Me

- 🔭 I work on **observability and enterprise platform engineering** — building dashboards, agents, and integrations that help teams see what's happening in their systems
- 🛠️ Hands-on with **Dynatrace** (DQL, Grail, dashboards, Cloud SRE Agents), **OpenTelemetry**, and cloud-native monitoring across AWS / Azure / GCP
- 💻 Also build with **Node.js / Express** and experiment with the **Anthropic API** and **Model Context Protocol (MCP)**
- 🌱 Currently exploring MCP and agentic AI workflows for observability use cases
- 📍 Based in the Dallas–Fort Worth area (Frisco, TX)
- ⚡ Fun fact: I like turning messy telemetry into dashboards people actually *want* to look at
